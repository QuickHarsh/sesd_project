# SpendSmart — Expense Tracker Web App

SpendSmart is a responsive web application that helps users manually track their daily expenses and visualize spending habits over time.
This project focuses on simplicity, clean UI, and core full-stack development concepts like CRUD operations, data visualization, and dashboard analytics.

---

## Project Goal

The goal of **SpendSmart** is to build a Minimum Viable Product (MVP) that allows a single user to:

* Log daily expenses manually
* Manage transactions easily
* View spending summaries on a clean dashboard
* Understand spending patterns through basic analytics

This project is designed as a beginner-friendly full-stack application.

---

## Scope

### ✅ In Scope (MVP Features)

* Single user data handling
* Manual expense entry
* Dashboard overview
* Basic analytics (totals & summaries)
* Transaction CRUD functionality

### Out of Scope (Phase 2 Ideas)

* Exporting data (Excel/PDF)
* Multi-currency support
* Recurring subscriptions automation
* Bank integrations

---

## Key Features

### Dashboard (Home Screen)

The dashboard gives a quick overview of financial activity:

* **Total Spent** — Displays total expenses for the current month
* **Recent Activity** — Shows the latest 3–5 transactions

---

### Transaction Management (CRUD)

Core functionality allowing full control over expenses.

#### Add Expense

Users can create a new expense using a form:

* Title (e.g., "Lunch at Joe's")
* Amount
* Date (default: today)
* Category (Food, Rent, Transport, Entertainment)

#### Edit Expense

* Update transaction details anytime

#### Delete Expense

* Remove incorrect entries with a trash icon

---

### History View

* View a complete list of all recorded expenses
* Optional filtering by category (Bonus Feature)
